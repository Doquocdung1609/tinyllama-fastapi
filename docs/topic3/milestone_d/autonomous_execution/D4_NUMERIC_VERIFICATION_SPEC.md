# D4 numeric verification specification, version 1

Supported operations are EXTRACT, COMPARE, ABS_CHANGE, PERCENT_CHANGE and PERCENTAGE_POINTS. The request names 1 or 2 unique D2 cell hashes, one exact source row label and optionally a measurement basis. Pydantic rejects extra fields and unrecognized operations. The verifier reconstructs the D2 bundle from authenticated source-context parent chunks, checks generation, manifest and evidence hashes, then requires `VERIFIED_CONTEXT` for every selected cell. It copies original source display, Decimal effective value, sign representation, multiplier, unit, reporting period, table/row/column, header path, source URL and structural locator into the claim.

Extraction returns the one effective Decimal. Comparison returns two ordered source values. Absolute change computes new − old. Percentage change computes `(new−old)/old*100` only for a strictly positive denominator. Percentage points require PERCENT source units; differences between percentages cannot use ABS_CHANGE. The fixed Decimal context has 28 digits and round-half-even. Input values and results have finite magnitude/exponent/precision bounds. No expression interpreter, arbitrary code, implicit currency conversion or missing-operand inference exists.

Comparisons require the same unit, filing, table, measurement basis, entity basis and accounting qualifier. Unknown entity basis, segment dimensions, mixed instant/duration and unlike duration widths abstain. Change operations require ordered old/new period identity. GAAP, non-GAAP and adjusted context are never silently mixed. The exact row label is preserved; revenue is not rewritten as net sales. `verify_claim` regenerates the claim from source-bound evidence and checks the full serialized object, including arithmetic, operands and citations.

`SUPPORTED` means that the typed calculation is supported relative to the trusted upstream source binding. It does **not** mean SEC bytes were independently cryptographically authenticated by D4, all values in an issuer's filing were found, or that an investment/financial answer is certified. A generic SEC link alone is insufficient: each operand includes a cell structural path and parent hash.
