`app/research_retrieval`: contracts (candidate/policy/result versions), service (D1 scope→pinned channels→fusion/rerank), ranking (dedup/RRF/table rule), adapters (accepted C private search under one outer query pin; B-only owned lexical adapter), snapshot (owned source-verified research dataset), evaluation (frozen metric definitions). No existing API/UI/default is modified. No vectors/embeddings are created by this stage.

Interface `retrieve_financial_query(question, explicit_filters, catalog, adapter, arm, policy, evidence_lookup)` returns financial-research-retrieval/v1 with scope JSON, effective route, full channel-ID pools, per-result reciprocal contributions/bonuses, timings and failures. Policy financial-research-policy/v1 freezes40/channel, RRF60, top5/10, rerank top20, row/role0.05 each, channel deadline≤30s. Scores are not probabilities.

Seven arms follow blueprint06/09 exactly: B/D/F controls, R router, T fixed-context rerank, A BM25-first conditional fusion, AT combined. Missing context earns no bonus; this does not make an unsupported real D2 table experiment successful. D1 nonresolved stops before channel calls. Candidate generation/manifest/CIK/filing/hash are checked; explicit observation periods require D2 cell-period membership, not just filing metadata. All channels operate under a single source-generation pin. Dense outage fallback is opt-in, labelled BM25_DEGRADED and excluded from scientific success. Integrity errors never take that fallback.

CSearchAdapter reuses C `_search` under the already established outer query guard. Calling public `search` inside that guard could deadlock against concurrent cleanup; tests reproduce the nested-call violation and verify B/D/F through actual C temporary-fixture code. This private-method dependency is explicit and must be reviewed if C changes. BoundedResearchVectors preserves Nomic prefixes/model contract with30s embedding I/O; production settings are unchanged. Deadline checks are cooperative/post-call plus bounded network I/O, not preemptive thread cancellation or a hard CPU guarantee.

Fresh real-source B uses a separate owned lexical index and C verified_source/ProvenanceCache(1 entry,32MiB); raw/structured/chunk bytes are hash-verified on requests and cache keys include generation/hashes/versions. No persistent evidence cache or owner index is opened. D/F are explicitly unavailable without compatible research vectors; no fixture vectors are passed off as real Dense embeddings.

Implementation/scientific states differ: the D3 code and real B diagnostics work; complete comparative research is **D3_BLOCKED_WITH_EVIDENCE** because Dense/F and real D2 contexts/categories are unavailable. D4 may implement a bounded verifier against supported synthetic source contexts; real numeric answers must abstain. See preregistration, baseline results and readiness.
