# P6 implementation checkpoint

Authorization: `TOPIC3_P6_REAL_SEC_AUTOMATIC_E2E_RECOVERY_AUTHORIZED`. Branch `codex/topic3-p6-real-sec-automatic-qa` was created from PR #15 HEAD `affa7979547c894dd894c827df50b3316528732a`, not from an accepted B/C branch. It is a separate stacked Draft PR candidate; no PR is merged and no accepted production route/default is changed.

The opt-in `workflow=automatic_real` path uses D1 to parse issuer/filing/period, then a source-backed alias bridge for the filing's self-declared “P&G” name. D1's `NEEDS_CLARIFICATION` status remains visible. Only its `COLUMN_PERIOD_METADATA_INCOMPLETE` reason can be refined after issuer and filing constraints are fixed. P6 queries the pinned research lexical index with an explicit 64-parent budget, preserves the original BM25 rank, checks exact row/metric, then calls P0 `verified_real_cells` on each bounded candidate. A single parent containing all requested typed periods is required. The P3 source-selected request is assembled **on the server**; the client supplies no parent, accession, cell or value. `answer_from_verified_real_cells` reauthenticates the source and uses D4's typed `calculate` with Decimal operands. No LLM selects numbers.

Modules: `app/research_qa/automatic_real.py` (policy and `ColumnRefinementV1`), `source_alias.py` (authenticated source self-alias), `real_cells.py` (D4 calculator bridge), `app/financial_query/period_resolver.py` (three-month expression), `app/research_api.py` and `research_ui.py` (opt-in workflow). The original `workflow=research` path and accepted Financial Search/Chat/RAG routes remain distinct. The new policy identifier is `p6-bm25-verified-cell-expansion/v1`; it is not D3/D5's evaluated adaptive finalist.

Supported automatic scope is intentionally narrow: one unamended filing, one exact `net sales` metric, USD/millions, explicit quarter-ended duration(s), and one source-verified parent row. Other metrics, instant values, fiscal-year shorthand, non-USD units, amendments, multiple filings and ambiguous cells abstain. The complete outcome and limitations are in the companion reports and JSON artifacts.
