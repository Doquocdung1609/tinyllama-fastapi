# P4 new evaluation preregistration proposal — not frozen for scoring

The old D5 held-out (SHA256 `70c52b601f3da535ad12d0041abf04df73832f8e9681058ae73e928e0e5bf843`) is consumed and is neither relabeled nor rescored. This document defines the **next** evaluation procedure; it is not a claim that a new held-out dataset or adaptive finalist exists.

Hypotheses to preregister before scoring: (H1) source-context authentication reduces false numeric claims at the cost of latency; (H2) BM25 remains stronger on exact rows; (H3) Dense may help paraphrases only if model identity and vector generation match; (H4) an adaptive strategy earns adoption only if it improves held-out relevance without increasing wrong issuer/period rates. Source groups must be distinct by issuer and filing; no issuer from the final held-out may be used for strategy selection. Record raw source hashes, accession, form and reporting periods before query authoring. Exclude the old HD held-out from strategy tuning.

Author labeled queries in at least exact line item, paraphrase, terminology, table context, comparison, instant balance, cash flow, EPS and refusal categories. For each, cite exact source cell IDs/locators and an annotation rule distinguishing issuer, filing, financial period, unit and sign. A separate reviewer should audit labels if available; otherwise record zero independent annotators. Freeze source files, split IDs, queries, qrels, scoring code, model identity, policy and selected finalist in a committed manifest **before first held-out execution**. Do not edit that manifest after scoring; create a new version for corrections.

Run B/D/F and one fixed adaptive finalist on the same authenticated snapshot only when all channels execute validly. Report Recall@5/@10, MRR@5, nDCG@5, wrong-issuer/period, evidence correctness, numeric answer accuracy, abstention precision/coverage, provenance failures, p50/p95 latency, memory/storage and per-query/per-issuer outcomes. Timeouts and unavailable models are operational failures, excluded from ranking-quality denominators and separately counted. No new held-out is frozen or scored in this checkpoint because a compatible Dense environment and independently grounded new source set were unavailable.
