# Proposed future independent evaluation — not yet preregistered or run

This document is a protocol proposal, not a frozen dataset or scientific result. The C and D5 held-outs are consumed. P9's PG/HD/COST sources were used for development and must not be called a new independent held-out. No new SEC acquisition or human annotations occurred in P9.

Before acquisition, define eligibility for *new* issuers with verified accession/form/source bytes and issuer-level exclusion from all B/C/D1/D2–P9 development, validation and consumed held-out issuers. Select a bounded set across fiscal calendars and statement structures using a published source-selection rule, not result-guided substitution. Freeze raw SHA256, accession, period, parser/chunker identities, manifest and generation. Acquisition must respect SEC access rules and an owner-approved storage/resource budget; do not overwrite accepted snapshots. Plan a small development split and issuer-disjoint final held-out; use development only for implementation choices.

Author source-grounded questions for exact metrics, paraphrases, table structure, comparisons, instant/duration, ambiguous issuer/period, unanswerable evidence, cross-filing conflicts, cash flow, EPS, segment and notes. Each qrel/answer label must cite authenticated parent and cell IDs, issuer, filing, period, unit, sign and relevant alternative columns; record explicit `UNANSWERABLE` where appropriate. Two independent human reviewers should label and adjudicate disagreements where feasible. If unavailable, record zero independent adjudicators and limit claims. LLM-generated answers are not ground truth.

Preregister hypotheses and a single fixed B/D/Fixed-RRF/Adaptive policy before held-out access. Same authenticated corpus and valid compatible vector snapshot for all arms; fixed top-k, BM25 parameters, model digest/prefixes, RRF constant, adaptive rules, timeout and exclusion criteria. Freeze queries, qrels, split, policy, scoring code and hashes in Git before first final run. Do not tune on held-out. Report per-query and per-issuer Recall@5/@10, MRR@5, nDCG@5, wrong issuer/period, source evidence correctness, numeric-answer accuracy, abstention precision/coverage, provenance failures, p50/p95 latency, peak memory/storage and operational failures separately. Use paired per-query differences with confidence intervals (for example issuer-cluster bootstrap when issuer count permits) and report sample-size uncertainty and negative results. No significance claim is warranted from a tiny sample.

Executable now: **NO**. Blockers are no live compatible Dense channel/vector generation, no newly acquired issuer-disjoint authenticated corpus, no independently reviewed labels and no frozen final strategy. The design must be versioned and approved before any new held-out run.
