# P9 performance and local resource envelope

Windows/Python 3.13.2; isolated research clone about 60.3 MiB; 18 development cases plus five repeated HD queries. `p9_resource_measurements.json` stores the final machine-readable run. Six heterogeneous positive controls took 1.59–3.75 seconds wall time (median 1.97 seconds; nearest-rank p95 3.75 seconds) in that warmed run. An earlier first execution observed 2.8–21.5 seconds across the same positive controls under colder source/OS cache conditions; its file was superseded by the final per-case schema run, so those initial values are observational context rather than the frozen machine series. Do not treat the pooled case quantiles as a steady-state service SLO. Five repeated warm HD queries in the final run took 1.49–1.62 seconds (p50 1.55 seconds, sample p95 1.62 seconds). Median warm instrumented stages were D1/scope 1 ms, BM25 candidate retrieval 319 ms, source authentication and cell derivation 573 ms, and D4 reauthentication/Decimal verification 590 ms. Provenance rehash/reparse is deliberately retained.

Backend object initialization in the final warmed process was about 5 ms; actual API and Streamlit cold startup were 1.69 and 4.15 seconds. The first real API HD query after startup took 2.44 seconds and its immediate repeat 1.77 seconds. Observed peak Python RSS for the acceptance probe was about 119 MB. At compatibility audit, Windows exposed 7.84 GiB RAM with about 0.75 GiB free, C: about 3.82 GiB free, and GTX 1650 Ti 4 GiB VRAM with about 3.94 GiB free. These are point-in-time local observations, not minimum specifications or a complete peak-load profile. One-slot API concurrency bounds simultaneous work; P7-style cloned publication/read probe is reported separately.

No cache or parameter change was made to reduce timing. A future optimization must preserve complete committed-source authentication, generation pinning and invalidation on any source/manifest change. No end-to-end GPU or Dense latency is reported because the vector channel was unavailable.
