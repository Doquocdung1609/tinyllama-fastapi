# P10 isolated Dense generation

`scripts/p10_build_isolated_vectors.py` built a **research-only** embedded Qdrant collection under `t3-p10-isolated-vectors-20261027-v1`. It did not open an accepted owner Qdrant collection. Source input was the previously isolated P7 clone; its lexical generation `8f0a7ba5ed851313a9948ddb465753c54012d94f9c36942239f7b2ec15b5e2fb` and manifest `86ad36365fbfb813e78e14246a48ae5735d7a8a1218f73daa4289caa98b215d0` were verified against the committed D3 source registry.

Each canonical parent was reconstructed from full authenticated raw, structured and chunk bytes via `verified_source`; filing/CIK/accession/URL and payload hash were checked before embedding. The exact 1,781-parent membership hash is `4522c70ba2c537bc150159e5e80a5f24d960066e0c9f4f4053230b66ead31b43`. Source raw SHA256 values are in `p10_generation_manifest.json`. All parent IDs used deterministic UUID5 point IDs; every point stores the pinned source generation, manifest and model digest. Collection policy: 768-dimensional COSINE, `search_document: ` prefix, first 6,000 characters, sequential batches of at most four. The P10 root has `identity.json`, atomic `progress.json` and `generation_manifest.json` for restart.

A 16-point pilot remained BUILDING. The resumed run added 1,765 points in 442 batches. Before READY, the builder scanned all points and required exact count, known unique parent IDs, valid payload identities, 768 finite coordinates and no missing parents. Final status: **READY, 1,781/1,781, zero missing**. Total isolated vector-root file size after completion was 14,773,411 bytes. Embedding request time in the resumed run summed to 437,352 ms; this excludes provenance scan, Qdrant insert and final validation. The local source clone and accepted owner data were not altered.

Run: `python -m scripts.p10_build_isolated_vectors --root <P7 isolated clone> --vector-root <P10 sibling root> --batch-size 4 --output docs/topic3/milestone_d/recovery/p10/p10_generation_manifest.json`. Re-run only on the same exact identity; a changed source or model fails closed. The READY artifact is local and intentionally not committed as vector bytes.
