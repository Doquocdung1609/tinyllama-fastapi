# P11 isolated development generations

The development generation is built only from the preregistered MCD and CAT filings in `C:\Users\Admin\.codex\research\t3-p11-new-sec-20261027-v1`. The accepted owner corpus, vector collections and production retrieval settings are outside this root. ORCL exceeded the preregistered 6 MiB source limit and was not replaced. Validation and held-out sources are not indexed in this generation.

`scripts/p11_build_dev_indexes.py` first checks the committed development freeze, raw source SHA256, structured parse, canonical chunk identities and issuer/filing membership. It builds a SQLite BM25 generation, then an embedded Qdrant collection under `index_dev/qdrant`. The fixed vector contract is `nomic-embed-text:latest`, digest `0a109f422b47e3a30ba2b10eca18548e944e8a23073ee3f3e947efcf3c45e59f`, `search_document: ` prefix, first 6,000 document characters, 768 dimensions and COSINE distance. The query prefix is `search_query: `. It checks the live Ollama digest before embedding, batches at most four sequentially, checks finite dimensions, checkpoints progress and requires 128 MiB free RAM and 1 GiB free disk as hard execution guards. Those are actual lower bounds, not a guarantee of system stability.

The lexical generation contains 2,887 canonical parents: 876 MCD and 2,011 CAT. A Dense generation is **READY only after** exact vector count, ID/payload binding, dimension and finite-value checks pass for every parent. `p11_embedding_manifest.json` records the observed final state. A BUILDING manifest must not be used for the B/D/F/A experiment. This script intentionally leaves an interrupted vector build as BUILDING and resumes missing points without changing membership.

The local raw SHA and canonical reparse bind local evidence to the bytes acquired from the official SEC URL. The local manifest is not cryptographically signed by the SEC. Both source parsers reported partial extraction; this generation does not certify every table or reporting column.
