# Audit of the original reference implementation's evaluation claims

Pinned public source: `satyam671/financial-hybrid-search-qdrant` at `16682dd42ca9cd4887ae74935cb3526dce580c49`. This is an audit of source code and reported artifacts, not a claim that the author intended to mislead.

1. `evaluation/golden_dataset.yaml` has 25 questions and `relevant_terms`, but no relevant chunk IDs, source pages, filing accession IDs or independent judgments. `BenchmarkRunner.run_benchmark()` computes `relevant_ids` by examining **only the returned top-k** from each method, then passes that list as the denominator to `IRMetrics.recall_at_k()`. The denominator changes with the retriever. Thus its reported Recall@10 is not exhaustive corpus recall. The executed synthetic counterexample in `AUTHOR_METRIC_COUNTEREXAMPLE.json` shows author-style 1.0 versus independently specified 0.5 for the same returned list. The counterexample is a code-path proof, **not** an empirical score.
2. `score_query_relevance()` is substring coverage of the query's term list, with threshold 0.5. The same generated relevance controls precision, MRR, nDCG and hit rate. These remain useful diagnostics of term overlap, but are not human judged financial relevance. The author's 96% should be described as an author-reported result under that method, not an independently verified Recall@10.
3. `NeuralReranker.__init__()` stores `model_name="colbert-ir/colbertv2.0"`; `rerank()` never loads weights or performs neural inference. It applies token overlap, regex-number bonuses, table-row flags, filing/year heuristics and a fixed weighted sum. Reproducing this pinned code is a deterministic reranker, not a neural reranker. The paper's qualitative stage-2 goal can still be tested separately.
4. The README quality table reports BM25 Recall@10 0.8133 and BM25+Dense 0.9600; committed `data/benchmark_report.md` reports 0.9600 for both and different MRR/precision. The PDF page 20 claims approximately 25.8/39.2 ms hybrid CPU time, whereas committed report lists p50 2403.71/3266.52 ms. The original per-query run, corpus manifest and environment fingerprint are unavailable, so these cannot be reconciled by assertion.
5. `config/default.yaml` contains `research@example.com` as a placeholder EDGAR contact. Do not use it to fetch SEC data. The repository's `data/` includes only the report, no raw 47 filings or 8,609 chunks.

The isolated original implementation's **31 unit tests passed, with two warnings**, after installing its declared dependencies plus FastAPI (needed by its API test but absent from `pyproject.toml`). That verifies unit behavior in the current package versions, not the paper's retrieval results. The test log is retained locally at `tmp/topic3/author-unit.log`; package versions and source hashes are locked separately.

## Consequence for Topic 3

Use `METHODOLOGICAL_REPLICATION` for bounded current-source experiments and `NOT_REPRODUCED` for original numerical claims until the exact corpus, model weights/configuration and independent judgments are available. Any new source-grounded qrels must be frozen before tuning; V3R3's 178 exposed queries remain development/regression only. Author-reported, locally rerun and independently evaluated metrics must appear in separate columns.
