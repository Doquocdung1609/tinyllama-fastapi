## FAITH-R ablation

`V5R_EXPERIMENT_POLICY.md` was written before the ablation. Every arm uses a Top-10 output budget. A0 runs original hybrid on recovered A; A1 original hybrid on corrected B; A2 adds safe issuer/fiscal metadata filtering; A3 adds table-like evidence sidecar candidates; A4 reorders by the V5 financial feature scorer; A5 adds conservative verification status.
