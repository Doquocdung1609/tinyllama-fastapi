# C4R ablations and negative controls

**A5_BASE** adds issuer/form-safe candidate retrieval, an English accounting expansion and period/financial-section ranking on immutable index B. `A5_FALLBACK` has the same 12/12 holdout result because the initial query already returned 60 internal candidates in every holdout question; **no second query was actually needed**. `A5_SIDECAR v1` had 12/12 too, but its appended rows were truncated after a full 60-candidate base pool, so this arm did not test effective sidecar contribution. The bug was found by auditing candidate IDs after the holdout. A versioned repair reserves five slots in the 60; on **four dev questions only**, five new original IDs entered the pool for one question, with **zero Top-5 changes**. See [development repair log](C4R_SIDECAR_REPAIR_DEV_RESULT.json). The held-out 12 were **not** rerun and relabeled independent after that repair.

The strongest faithful author Stage-2 heuristic uses 60 internal SPLADE+BGE candidates for Top-20 output. A5_BASE also caps its BM25+BGE internal pool at 60, but applies an issuer/form filter and a read-only source report-date map. The budgets are equal in *candidate count*, not embedding latency or retrieval algorithm. A5_SIDECAR's 8,670-payload scan is extra compute and cannot support an equal-cost claim. Native author RRF is Qdrant default **k=2**, as in G3U v2; no k=60 result is invented.

The 12-question new English set has one paired A5_BASE improvement over Stage-2 at Top-5 and source-enriched answer, 11 ties and zero A5 regressions. A5's old A4 predecessor lost 18/67 paired G2 cases to BM25+BGE RRF in C4; that exposed finding is preserved. A5 source-enriched correctness is driven by first finding the filing and then the common iXBRL verifier; it is **not** evidence that A5's Top-1 original chunk contains the right financial cell. Original-only answer accuracy is 0/12 with 12 explicit abstentions for both methods. Comparatives and narrative/negative answers are not covered by the 12 source-derived numeric facts.
