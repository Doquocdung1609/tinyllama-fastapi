# Top-1 metric precision repair

Root cause: V3R2 used capped FTS5 relevance and a metric boost. The boost worked when a row label was classified, but OCR-damaged target rows were sometimes unclassified. A different known metric or generic narrative could then take Top-1. Dense retrieval contributed candidate chunks; the locked Nomic vectors and their digest were unchanged. Source eligibility still rejected these chunks, so this was a ranking problem rather than a false reviewed financial answer.

The original Top-10 is preserved in `../search_v3r2/AFTER_178_COMPATIBILITY_RESULTS.json`. The final V3R3 178-query Top-10 is reconstructed without changing individual records in `AFTER_178_CEO_RECONSTRUCTED.json` from `AFTER_178_CEO_FINAL.json.progress.jsonl`. The harness completed all queries but its second prewarm was deferred by the 768 MiB RAM guard. Neither qrels nor old result files were edited. `TARGETED_7.json`, `AFTER_178_FINAL.json` and `AFTER_178_RELEASE.json` retain intermediate experiments, including an ACB Top-5 regression from a broader phrase bonus that was removed.

Repair:

- A known mismatched metric receives a ranking penalty. A matching metric is unchanged. An unclassified source row stays unclassified; it is not counted as a correct metric.
- On a confirmed income-statement context, the source label `60 Lợi nhuận thuế TNDN` creates a provisional retrieval candidate `60 Lợi nhuận sau thuế TNDN`. The CEO source row with formula `(10=01-02)` and `vụ` creates a provisional net-sales candidate; the REE balance-sheet row code `230` with damaged property wording creates a provisional investment-property candidate. These are source-anchored Vietnamese accounting-line patterns. Raw PDF/OCR, numeric cells, confidence and coordinates remain intact. No issuer, document, query ID, page or value appears in the runtime rule.
- A specialized phrase such as continuing-operations profit can favor its exact source row without claiming the broader total-net-income metric.
- Existing metric, issuer, period, basis, scope and unit conflict checks still govern `numeric_answer_eligible`; the score adjustment cannot set that field or create a reviewed fact. Related passages remain available below stronger evidence.

Counterexamples include pretax versus after-tax, financial revenue versus net sales, current assets versus investment property, other profit versus net income, and specialized continuing-operations profit versus total profit. The focused unit tests exercise matching, mismatch and unclassified cases. Full evaluation also checks whether any previously located source leaves Top-5.
