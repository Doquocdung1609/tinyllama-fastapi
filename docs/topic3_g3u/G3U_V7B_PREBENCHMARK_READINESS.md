The owner approved a versioned v2 candidate acquisition after the pinned author RRF discrepancy was disclosed. The original v1 attempt remains a private, aborted 16,020-hit checkpoint; it was not used to tune methods. V2 generated a complete blind union from 1,692 runner-asserted arm/question/index executions, yielding 31,760 ranked hit lines and 5,792 unique `(question_id, original_chunk_id)` pairs. Of these, 3,946 are outside the target filing. Rank, score and arm identity are absent from the blind review queue; the union and original text hashes passed an independent structural audit.

The per-hit log lacks separate execution rows for 104 arm/question combinations with no ranked hits. The runner asserted all 1,692 calls, but a third party cannot distinguish a true zero-result run from an omitted call from that file alone. This is a documented run-provenance limitation, and a future runner version should write an execution record even for zero hits. The approved v2 pool is not rerun to cosmetically remove this limitation.
