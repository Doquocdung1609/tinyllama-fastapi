# V6 experiment diary (actual events)

1. **V5R reproduction discrepancy:** 2/90 P7L A rows did not reproduce exact order. Saved-score comparison isolated a dense near-tie inversion and its RRF propagation on GOOGL_FY2024. Same Top-10 set and Top-1. Original query vector/P3C unavailable; precise numerical cause remains unresolved. No result was edited to hide it.
2. **Review queue not gold:** all 30 V5R proposals had empty source-cell fields and UNJUDGED labels. Source-first original SEC HTML was downloaded/reused at one request per second; 30 pilot packets and 30 fresh packets were machine-prepared. No human adjudication was available.
3. **Fresh-split design correction before evaluation:** first 30-question draft owner-machine byte SHA `419262dd...` overrepresented metrics outside the frozen FAITH-R parser. It was replaced before any retrieval or label exposure with the LF-normalized accepted SHA `01e841d...`, containing 18 supported-metric/comparative and 12 broader questions. The first draft is not claimed as an evaluation. No final-split ranking was run.
4. **Packet-generation QA:** initial HTML output had trailing whitespace from empty SEC table cells. The generator was corrected to trim line endings and packets regenerated. Candidate spans remain unverified machine suggestions. The unsupported FY2037 pilot packet still lists historical net-income rows, illustrating why a textual match is not an answer to a future-period question.
5. **Counterfactual ablation script:** first invocation failed with `ModuleNotFoundError: app` because the project root was not on `sys.path`; import path was fixed. The rerun reproduced frozen A4 exactly on all 15 saved pools. Removing metric-relation features reduced exposed known-positive Top-1 from 10/15 to 3/15; issuer/fiscal removals did not change it because A2 already filtered them. Unit and column-year are absent features, so they were not faked as ablations.
6. **Pilot execution:** a one-question/ten-method smoke passed, then the remaining 29 pilot questions ran live on corrected B. All 300 method runs completed. The FY2037 question returned zero A2/A3/A4/A4R hits; original unfiltered methods still returned chunks. A3 added candidate IDs in 7 cases; A4 and A4R changed Top-1 in 9 and 10 cases. No qrels exist, so these moves cannot be scored as improvements.
7. **Persistent exposed failures:** A4R's Amazon FY2023 top result remains UNJUDGED after a previously YES A4 result; Intel FY2024 remains UNJUDGED. Meta's 2025 forecast and Tesla's prose-vs-table miss show why top filing alone is insufficient. No new repair was made after pilot outcomes; the frozen comparison remains intact.
8. **Candidate-budget regression:** reranking saved A3 pools with frozen A4 at k=10/20/50/100 reproduced A4@10 but reduced exposed known-positive Top-1 from 10/15 at k=10 to 9/15 at k=100. Unknown positions increased sharply. More retrieval did not guarantee better source ranking; no budget parameter was retuned.
9. **Cross-platform hash gate:** the initial fresh queue CSV used Windows CRLF, while Git stores normalized LF on Linux. Local tests passed but CI's byte-hash assertion failed once. The queue writer was fixed to emit LF, and packet/compact-result hashes were changed to normalized text hashes across operating systems. Question and ranking content did not change, the final split was not run, and CI was rerun. This was a provenance/portability defect, not an evaluation outcome.

The diary records failures and corrections actually observed, not hypothetical attempted experiments. Full pilot text remains local and its checksum is in the summary; tracked compact rankings preserve the replayable evidence without committing the SEC corpus.
