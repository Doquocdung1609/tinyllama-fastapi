# P7L A: the two ranking discrepancies

The only two mismatches among 90 P7L A live/historical method rows are `GOOGL_FY2024` dense and BM25+Dense. Both retain the **same Top-1 and identical Top-10 ID set**; the order changes inside that set. Exact old/new score and rank pairs are in `V6_P7L_DISCREPANCY_DATA.json`, generated by `scripts/topic3_v6_discrepancy.py` from saved historical and live rows.

Dense ranks 6/7 exchange chunks `..._0109` and `..._0075`. Historical cosine scores are 0.7532716510 and 0.7532715378, a gap of approximately 0.0000001132. Live scores are 0.7532641001 and 0.7532678614, reversing that near tie. The BM25+Dense result then exchanges ranks 5/6 (`..._0109` and `..._0110`); `..._0109` RRF score changes from 0.2857142857 to 0.2678571429 while `..._0110` stays 0.2763157895.

**Demonstrated cause to the observable level:** a small dense-score/order change propagates into RRF. The sparse IDF modifier alone cannot explain the dense-only inversion. The same Top-10 set and immutable vectors rule out a missing candidate or corpus text difference for these ten hits. Exact root cause remains **UNRESOLVED** because the historical query vector and exact original P3C index are unavailable; query embedding execution, Qdrant version/numerics, and recovered-index construction cannot be isolated from saved results.
