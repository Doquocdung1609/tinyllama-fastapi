## Engine and contract

There is one answer engine. The existing V2 source-cell/Decimal pipeline executes per typed requested slot. The independent numeric module still reopens original cells and recalculates from verified operands; it does not trust generated math. The separate `semantic_answer_gate.py` compares requested metric/category, geography/report scope, periods, operation and output dimensions with actual verified claim metadata. It also checks declining-segment selection and proposed-amount confirmation. Literal explanations are read from original native PDF blocks and checked by source SHA, location and exact text.

Returned fields include `primary_answer`, `supporting_claims`, `calculation_steps`, `citations`, `unanswered_subquestions`, `limitations`, `semantic_question_coverage`, `source_numeric_verification`, `generation_status`. SQLite sessions retain the older answer fields; migration is additive. Legacy retrieval profile key `faith_r_product_v1` remains compatible. Native targeting identifies its actual algorithm as `FAITH_R_NATIVE_CELL_TARGETING_V3`; no baseline is relabeled FAITH-R.

`candidate_count` is the bounded considered pool, not a relevance count or corpus size. `matching_evidence_count` is a separate FAITH-R matching count; raw arms leave it unclassified. `verified_value_count` counts distinct independently verified source-cell IDs, not citations or requested TopK. TopK is a cap, and unavailable sources have no executed mode/profile. A private bounded candidate-limit argument supports explicit scope filtering without changing normal raw-arm scoring or the public Top20 cap.

## Limits deliberately retained

1. HPG Q4/year numeric cells remain OCR-unverified. The product opens PDF5 and states the column/coordinate limitation; it does not certify AI visual guesses.
2. SEC remains BLOCKED without compatible source snapshot/index. The UI disables unavailable SEC; no locked research index or alternate corpus was substituted.
3. Semantic verification is bounded to supported financial slots and source layouts, not arbitrary-language entailment. Extra multi-year U.S./Americas requests are honestly partial when the composer has not resolved every year. New unsupported metrics/quarter explanations stay unverified with specific reasons, not a blanket OCR excuse.
4. Adjustment lists are explicitly partial, with semantic coverage marked PARTIAL rather than a claim of exhaustive rows.
